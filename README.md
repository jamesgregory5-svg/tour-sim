# Daily Sim ⛳ — golf simulator (fan-made)

A browser golf simulator with no characters: just the ball, the course, the tracer and a launch monitor. **[Play it](https://jamesgregory5-svg.github.io/daily-sim/)**. It is one self-contained `index.html` with no external requests, so it also works opened straight from disk (`file://`).

*Work in progress: full notes are coming with the final build.*

Fan-made; layouts approximate; not affiliated with any club.
